THE REAL-WORLD CONNECTION

Built from real failures.

We designed this challenge around the kinds of mistakes seen in these three incidents. Their lessons shape the lab’s access rules, backup boundaries, and logging requirements.

01 / DOCUMENT ACCESS2019

First American

A document link opened too many doors.

A flaw in EaglePro allowed document identifiers in links to be changed to reach unrelated documents without authentication, as described in the New York regulator’s findings.

In this lab

Check who can access a document through a direct request.

Read the NYDFS findings ↗ (PDF)
02 / BACKUP EXPOSURE2023

Microsoft AI research

A shared link reached private backups.

Wiz reported that an overly broad Azure sharing token exposed 38 TB of private data, including two employees’ workstation backups, while researchers shared AI models.

In this lab

Review the backup route as carefully as the main application.

Read the Wiz investigation ↗
03 / SENSITIVE LOGS2018

Twitter

Passwords ended up in an internal log.

Twitter disclosed that a bug wrote passwords to a log before hashing. It removed the passwords and reported no indication of a breach or misuse.

In this lab

Keep useful security events while leaving secrets out of logs.
